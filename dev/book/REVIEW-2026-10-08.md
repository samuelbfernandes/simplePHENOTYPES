## Corrections made (summary)

- **input**: the `counted_allele` attribute is kept unchanged (stale) by row subsetting,
  not dropped; `impute = "Major"` fills the homozygote coded 1 after orientation; numeric
  tables also carry `cm`; filter removal counts are now printed and the prose matches them.
- **founders**: the GENERIC coalescent preset is bottlenecked, so its spectrum is not
  skewed toward rare variants; unphased outbred founders produce spurious coupling LD from
  the first cross on.
- **nonadditive**: scalar `a` is a geometric base, so the degree-of-dominance example now
  passes constant vectors; centered epistatic products are orthogonal to main effects
  under linkage equilibrium at any frequency (LD, structure, and d-type factors break it).
- **multitrait**: correlation scatter is dominated by finite effect-pair sampling, not LD;
  MAF scaling converts per-SD effects to per-allele effects.
- **binary, complex**: a `complex_phenotypes()` result cannot be thresholded; prevalence
  spread has three causes; the combined-correlation formula needs equal per-trait shares
  (general form added).
- **trait**: inbreeding without selection raises the fixed-scale among-line additive
  variance, so h² rises.
- **prediction**: G diagonal is about 1 + F; the training-size design now draws records in
  a fixed random order; a moving base deflates relatedness.
- **selection**: the Smith-Hazel index ranks phenotypes; only the quadratic index ranks
  true breeding values.
- **markers**: cohort expectation is 1/2 + 1/2 × parent recovery from BC2 on; only BC1 is
  shared between the two schemes.
- **expression, mediation**: a gene with no cis marker still realizes trans heritability;
  the kappa estimator description matches current code; component variance (not share) is
  equal across gene sets.
- **output, legacy**: wide-table shape, structural A-D covariance, plot-panel scope,
  always-present LD columns; legacy h² = 0 and `cor_res` caveats, print reports the mean
  over replications, the legacy AD example uses separate dominance loci, legacy `cor` exists,
  single-trait `to_r` column names.

## Package issues found (not fixed in the book; flagged as separate tasks)

- `complex_phenotypes()` carries the first input's `threshold`/`liability` into the
  combined object, so `print()` and `coheritability()` read a stale liability table
  (`R/grammar_complex.R` ~162); the `liability_threshold()` error text points users to the
  wrong workaround.
- `mate()` and `population_from_haplotypes()` use `$` on tibbles and emit spurious
  "Unknown or uninitialised column" warnings.
- `create_phenotypes()` with a relative `home_dir` nests output one level deeper.
- `man/epistasis.Rd` (lines ~71-73) repeats the incorrect non-orthogonality claim fixed in
  the nonadditive chapter.
- `print()` labels a pleiotropy layer "(n QTNs, geometric)" although its effects are
  multivariate-normal draws.
- Legacy residual seed `(seed + j) * round(h2 * 10)` is zero for every replication when
  h² < 0.05, giving identical residuals across replications.
- Equation map entries V2-crossing-3, V2-transcriptome-12, -19, -20 are stale relative to
  the code; transcriptome line numbers are off by about 130.
